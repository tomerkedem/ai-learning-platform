# Docs - מאחורי הקלעים של AI

תיקייה זו מרכזת את מסמכי העוגן של הלומדה **מאחורי הקלעים של AI**.

שם התיקייה צריך להיות:

```text
docs
```

לא `Doc`, לא `DOC`, ולא `Docs`.

## סדר קריאה מומלץ

1. `behind-ai-final-chapter-plan.md`  
   תוכנית 19 הפרקים הסופית, כולל עוגן החבילות והמשלוחים.

2. `behind-ai-chapter-template.md`  
   תבנית פרק רשמית ללמידה עצמית פעילה.

3. `behind-ai-i18n-rules.md`  
   כללי i18n, RTL/LTR, שמות שפות, ושמירת מונחים מקצועיים.

4. `behind-ai-visual-rules.md`  
   כללי UI, מנטורים, דמויות, כיווניות, ואיסורי טקסט.

5. `behind-ai-animation-rules.md`  
   כללי אנימציה מתקדמת, אינטראקציות חכמות, חוויית למידה ברמת 2026.

6. `behind-ai-mentor-rules.md`  
   כללי שילוב מנטור בפרקים, במקומות נבחרים ובתפקיד פדגוגי ברור.

7. `behind-ai-claude-workflow.md`  
   דרך העבודה המומלצת מול Claude Code.

8. `behind-ai-implementation-roadmap.md`  
   סדר עבודה בטוח לשינויים הבאים בפרויקט.

## עקרונות על

- לא קוראים ללומדה ספר או ספרון.
- Hebrew is the canonical source.
- הלומדה מתוכננת לתמיכה ב-6 שפות: he, en, es, ru, ar, ja.
- כל פרק צריך ללמד רעיון אחד מרכזי.
- החל מפרק 3, כל פרק צריך להיות פעיל: ניחוש, ראה, גע, נעילת הבנה, תובנה מעשית, מבחן.
- עוגן הדוגמאות המרכזי הוא חבילות, משלוחים, מעקב, מסירה, סטטוסים ו-Agent סביב משלוח.
- אנימציות אינן קישוט. כל אנימציה חייבת ללמד משהו.
- המנטור אינו קישוט. כל הופעה שלו צריכה לקדם הבנה, ביטחון או סקרנות.
